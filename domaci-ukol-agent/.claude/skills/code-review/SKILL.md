## Pravidla kontroly

1. Zkontroluj skutečný diff i související projektové instrukce.
2. Hledej pouze potvrditelné chyby: argumenty, cesty, tajemství, konfiguraci,
   syntaxi, bezpečnost a nesoulad se zadáním.
3. Ověř claim příslušným výstupem, řádkem nebo potvrzeným stavem souboru.
4. Nevytvářej úlohy pro obecné stylistické preference bez ověřitelného důvodu.
5. Nepřidávej změny; návrh opravy předlož vedoucímu agentovi.

## Výstup

U každého problému uvedeš: soubor a řádek, důkaz, dopad a navrženou opravu.
Pokud problém nenajdeš, napiš to explicitně a uvedeš použité ověření.
